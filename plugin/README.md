# DSH Agent 预设编辑器 3.0.1

在 DSH 原生设置窗口右上方点击 **编辑 Agent 预设**。在 Agent 预设页也可直接使用这个入口。

支持编辑显示名称、说明、排序、前置与后置人设提示词；支持复制现有预设并创建新 ID。工具清单和 `!!js` 条件按原模板保留，多个人设段落可分别选择。已有预设 ID 固定，以免旧会话出现 `Unknown agent preset`。

保存通过 DSH 的 `configEditor.edit()` 校验、原子落盘和热加载。新预设保存为编辑器配置中的正式 `@deepseek-ai/dsh-agent-preset` 声明，使用官方 Loader 与注册表。运行中的 Agent 保留已有配置，新任务使用新配置。配置在另一处发生修改时会拒绝覆盖，保留编辑内容。

无需退出 DSH，不需要外部 EXE，不会改写会话日志。原生预设卡片、默认选择和配置查看功能继续由 DSH 提供。插件通过 `settings.action` 官方插槽展示，编辑对话框由这个设置入口持有，不修改其他插件 DOM，不修改 DSH 安装文件。

## 安装

通过 DSH 插件管理器安装本目录或发布的 TGZ，或运行官方 CLI：

```powershell
dsh plugin --profile desktop add "file:C:/plugins/dsh-agent-preset-editor-3.0.1.tgz"
```

更新已有安装后按 DSH 提示重启。适配 DSH Desktop 0.2.0-rc.2。

3.0.1 修复打开时的抽动：窗口从加载第一帧起保持相同尺寸，内部内容独立滚动；滚动条预留宽度，焦点切换不滚动背景。打开采用 120ms 淡入，遵循减少动态效果设置。

## 使用与限制

- 修改显示名称即可重命名预设。已有 ID 不可改；需要不同 ID 时使用“复制为新预设”。
- 排序允许 0，留空恢复未指定的排序。
- 编辑会完整保留非人设配置；前置、后置文本分别保存，空行与缩进不自动修剪。
- 根配置中的预设和此插件新建的预设可编辑。其他插件直接注册且没有可编辑配置入口的预设显示为只读。
- 表达式生成的人设只读，避免将表达式覆盖成空文本。
- 卸载或禁用此插件会撤回它创建的预设。已有会话仍引用这些 ID，恢复这些会话前应重新启用插件。
- UI 与 Agent 工具 `dsh_persona_editor` 共用保存逻辑；Agent 写入沿用 DSH 的 Full access / 单次审批策略。
- 不提供删除已有预设和修改已有 ID，避免破坏会话关联。

本插件不包含任何用户人设。私人人设和预设内容只保存在当前 DSH 配置中。

## 验证

```powershell
node --test tests/*.test.mjs
```

覆盖人设与工具的隔离修改、固定 ID、嵌套段落、表达式保留、空行保真、相对模块路径、并发修改与重复 ID。

在 Windows 上还可用已安装的 DSH 运行原生集成测试：

```powershell
powershell -File tests/run-native.ps1 -DshDirectory "D:\dsh"
```

测试创建独立临时 profile，使用实际 DSH 的配置编辑器、Loader、预设与工具注册表；验证保存、新建、冲突拒绝、创建失败回滚、运行中配置保留及重启恢复，不读写你的会话或人设。桌面界面另经浅色、深色、弹窗层级和 Escape 返回检查。
